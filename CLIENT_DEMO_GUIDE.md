   - Browse 12+ product categories

   - Filter by price, MOQ, certifications, origin
   - View product details with supplier ratings

2. **RFQ Management**
   - Create multi-product RFQs
   - Specify quantities and specifications
   - Set target prices and deadlines
   - Track RFQ status

3. **Quote Comparison**
   - Receive quotes from multiple suppliers
   - Compare prices, lead times, terms
   - Accept/reject quotes
   - Convert to purchase orders

4. **Order Tracking**
   - View order status
   - Track shipments in real-time
   - Document management
   - Communication with suppliers

### For Sellers

   - Add/edit products
   - Upload product images
   - Set pricing and MOQ
   - Manage certifications

   - View incoming RFQs
   - Submit competitive quotes
   - Negotiate terms
   - Track quote status

3. **Order Fulfillment**
   - Process accepted orders
   - Update shipment status
   - Upload documents
   - Communicate with buyers

## 🏗️ Technical Architecture

### Frontend Stack
- React 18 with TypeScript
- Vite for fast builds
- Tailwind CSS for styling
- Lucide React icons
- React Router for navigation

### Mobile Stack
- React Native CLI 0.82
- TypeScript
- Redux Toolkit for state management
- React Navigation
- React Native Paper UI

### Backend Stack
- Node.js with Express
- PostgreSQL 16 database
- JWT authentication
- Bcrypt password hashing
- Multer for file uploads

### Infrastructure
- Docker containerization
- Nginx reverse proxy
- SSL/TLS encryption
- Contabo Object Storage
- Brevo email service
